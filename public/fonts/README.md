# UI faces
`cinder-9.ttf`, `cinder-12.ttf`, `cinder-13.ttf` — "Cinder Pixel", a bitmap-style bold serif built by
`build_pixelfont.py` from DejaVu Serif Bold (Bitstream Vera licence, derivatives allowed; see LICENSE-FONTS.txt). Each face is crisp at integer
multiples of its base size: 9→18/27, 12→24/36/48, 13→26/39. Rebuild: `python3 build_pixelfont.py <src.ttf> <px> <out.ttf> [--dilate]`.
